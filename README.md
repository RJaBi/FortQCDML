FortQCDML is designed to handle International Lattice Data Grid ([ILDG](https://hpc.desy.de/ildg/)) XML metadata formats -- called QCDML.


Currently the code supports only production of configutation metadata for the `2.0.1` schema. Note that the optional, extended XML entries in the schema are not supported.

Rather than write XML, one writes toml and then uses this code to make it into the required QCDML document.
